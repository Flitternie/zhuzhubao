# 猪猪包的特征表

根据 `photos/` 里的 10 张照片和主人的说明整理，每次生成形象时都要带上。

## 特征

| 部位 | 特征 |
|---|---|
| 整体 | 白色长毛感的圆润猫，毛蓬松，体型敦实，身体宽 |
| 毛色 | 底色白到奶白；背部和身体侧面有极淡的银灰色毛尖 |
| 头 | 大而圆，脸宽，两腮饱满，下巴小 |
| 耳朵 | 小，圆头，分得较开；内侧粉色，耳背和边缘带淡银灰 |
| 眼睛 | 大而圆，有明显的深色眼线；白天是蓝色，晚上偏黑（瞳孔放大），应用内按本地时间切换 |
| 鼻子 | 小，粉色；鼻梁上是很浅的灰色渐变，逐渐融入白毛，不能画成深色色块 |
| 表情 | 嘴小；真猫有点小脾气，但桌宠以可爱耐看为先：默认眼睛圆睁、神情平和，不画压低的眼睑或皱眉 |
| 胡须 | 白色，细长 |
| 脚 | 短而圆，白色；肉垫深色，接近黑色 |
| 尾巴 | 粗而蓬松；尾尖白色，靠近尾根到中段有灰褐色环纹 |

## 生成时不能丢的 5 点

1. 圆脸大头，下巴小，身体敦实
2. 大圆眼加深色眼线
3. 粉鼻子，鼻梁很浅的灰色渐变
4. 粉色内耳，耳背淡银灰
5. 蓬松尾巴，尾尖白色，尾根到中段有灰褐色环纹

## 对生成的影响

- **左右镜像：** 这些照片里没有看到明显的左右不对称花纹，走路动画暂定可以镜像，省去一半帧数。尾巴环纹在镜像后也不会明显出错。
- **白猫的轮廓：** 白猫放到白色窗口上容易融进背景，需要一圈深色外轮廓，这条是硬性要求。
- **去背景：** 不能用白色或浅色背景生成，否则去背景时容易吃掉猫，要用高饱和的纯色。
- **像素细节：** 淡银灰毛尖在低分辨率下基本画不出来，只保留耳背、鼻梁和尾巴上的灰色。

## 参考照片

裁剪后的照片在 `photos/cropped/`，原图未改动。裁剪只去掉了大部分环境，部分照片还留有背景物品，上传前再看一遍。

| 文件 | 用途 |
|---|---|
| `walk-from-above.jpg` | 唯一的走路照：俯视角度，尾巴竖起，眼睛呈蓝色 |
| `sit-front-daylight-tail.jpg` | 正面坐姿，腿和前脚清楚 |
| `sit-front.jpg` | 主参考：正面坐姿，脸、胸、前脚最清楚 |
| `sit-front-small.jpg` | 坐姿补充，分辨率较低 |
| `sit-three-quarter.jpg` | 3/4 侧面的坐姿、身体比例、尾巴 |
| `loaf-tail.jpg` | 尾巴环纹最清楚；窝着的姿势 |
| `loaf-sleepy.jpg` | 半眯眼的表情，趴着 |
| `lying-side-front.jpg` | 身体长度，趴姿 |
| `sprawl-paw-pads.jpg` | 侧躺放松的姿势，深色肉垫 |
| `sprawl-sleeping.jpg` | 睡觉姿势 |
| `groom-paw.jpg` | 正在舔爪，是舔毛动作的直接参考 |
| `lying-pose-redeye.jpg` | 只参考姿势和体型；闪光灯造成红眼，不能参考眼睛 |

**缺少：** 站着或走路的正侧面全身照。`walk-from-above.jpg` 是俯视角度，看不准腿长和身体高度，这两项目前要由 AI 推测。

**走路姿态：** 走路时尾巴竖起，尾尖微微弯曲。

## 生成新动作时的风格控制

新动作用 PixelLab 生成（`/animate-pixminimax`，第一帧用已定稿的帧），**每次都把下面这段放进 `subject_description`**（上限 300 字符）。动作描述末尾再加一句 "Keep exactly the colours, face, eyes and proportions of the first frame."

```
fluffy cream-white cat, light warm grey shading, thin dark grey outline; big round deep-blue eyes with thick dark eyeliner; small pink nose; pink inner ears; dark grey-black paw pads, never pink; fluffy tail with white tip and grey-brown rings from base to middle
```

生成后对照原帧检查这几项，常见的偏差：

| 项目 | 应该是 | 生成常出现的问题 |
|---|---|---|
| 肉垫 | 深灰近黑 | 画成粉色肉球 |
| 眼睛 | 深蓝、粗深色眼线 | 偏亮偏青；张大眼露眼白显得受惊；凶眼 |
| 毛色 | 奶白，阴影很浅、偏暖 | 整体偏灰、偏暗，或者偏冷的蓝灰 |
| 尾巴 | 白尾尖，尾根到中段灰褐环纹 | 环纹变浅灰或消失 |
| 嘴 | 张嘴时里面是深粉色 | 嘴里画成纯黑 |
| 胡须 | 细浅灰线 | 侧脸时嘴边一团深灰 |

脚本只改颜色、不改形状（`app/tools/style/`）：`mm_clean.py` 对齐地面、去杂点 → `degreen.py` → `stylefix.py`（毛色亮度和虹膜按分位数对齐参考帧；比参考偏冷的毛才换成参考的暖色；`--pads` 指定区域里的粉色改成深色肉垫）→ `facefix.py`（嘴里的黑块、胡须团）→ `softedge.py`。形状上的问题（脸画坏、凶眼、肉垫形状）只能重新生成。
