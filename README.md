# 猪猪包

一只像素风的 macOS 桌面猫，照着真猫猪猪包画的：会走路、趴窗口、扒墙磨爪、伸懒腰，提醒你喝水、起来活动和看日程。

**下载：** 到 [Releases](https://github.com/Flitternie/zhuzhubao/releases/latest) 下载 `Zhuzhubao-<版本>.dmg`，把猪猪包拖进 Applications。第一次打开要在「应用程序」里右键点它 →「打开」。装好以后有新版本会自动提醒更新。

需要 macOS 13 或更新版本，Apple 芯片和 Intel 都可以。

代码、构建和发布说明在 [app/README.md](app/README.md)。
