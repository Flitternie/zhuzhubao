# 猪猪包桌宠（macOS）

## 构建和运行

```sh
cd app
./build.sh                  # 用 swiftc 编译，生成 build/猪猪包.app
open build/猪猪包.app
```

`./build.sh install` 会再复制一份到 `~/Applications/猪猪包.app`（开机自启动用这个位置），并关掉正在运行的那只。

### 打包发给别人

```sh
./package.sh                # 生成 build/猪猪包-<版本>.dmg（版本号在 VERSION 文件里）
```

DMG 打开是一个像素风安装窗口：粉蓝天空、云朵，猪猪包图标和「Applications」之间有一排粉色箭头，猫在地板上往 Applications 走、头上冒小心，底部写着第一次打开的方法。背景由 `tools/make_dmg_bg.py` 生成（`packaging/background*.png`），窗口布局由访达自己写入（macOS 26 不认第三方工具写的布局），所以打包时访达会闪一下窗口，第一次可能要允许终端控制访达；打包前要先推出已挂载的「猪猪包」磁盘。.dmg 文件本身和挂载后的磁盘都是猫头图标（文件图标经部分聊天软件转发后可能丢失）。程序同时支持 Apple 芯片和 Intel 的 Mac（macOS 13 起）。图标由 `tools/make_icon.py` 从 `assets/zhuzhubao/app-icon-source.png` 生成（`assets/` 和 `photos/` 只留在本机，不放进 GitHub）。

默认是本机临时签名（ad-hoc），别人第一次打开要右键 →「打开」，或到「系统设置 → 隐私与安全性」点「仍要打开」。有 Apple 开发者账号（99 美元/年）的话可以正式签名并公证，打开就不会被拦：

```sh
ZHUZHU_SIGN="Developer ID Application: 名字 (TEAMID)" ZHUZHU_NOTARY_PROFILE=钥匙串里的公证配置名 ./package.sh
```

### 发布新版本（自动更新）

装好的猪猪包用 [Sparkle](https://sparkle-project.org)（`vendor/sparkle`，2.10.0）每天检查一次 GitHub 上最新 Release 里的 `appcast.xml`。发现新版本后自动下载、校验签名，猫说「我去换身新毛毛，马上回来～」，3 秒后自动安装重启，回来后说「更新好啦！」。只有无法自动安装时（比如 app 所在文件夹没有写权限）才冒泡问「要更新吗？」。菜单里也有「检查更新…」。测试：`ZHUZHU_FEED=http://127.0.0.1:端口/appcast.xml` 指向本地 appcast，加 `--update-test` 立刻检查。

```sh
./release.sh 1.2 "伸懒腰更舒展了" "修好了晚上水碗变空的问题"
```

`release.sh` 会：版本号写进 `VERSION` → 打包 app 和 DMG → 用钥匙串里的 Sparkle 私钥（账户名 `zhuzhubao`）给更新包签名 → 生成 `appcast.xml` → 提交并推送 → 在 `Flitternie/zhuzhubao` 发 Release（`Zhuzhubao-<版本>.zip`、`.dmg`、`appcast.xml`）。后面每个参数是一条更新说明。

- 私钥只在这台 Mac 的钥匙串里（「钥匙串访问」里搜 Sparkle），**换电脑或重装系统前要导出备份**：`vendor/sparkle/bin/generate_keys --account zhuzhubao -x 私钥文件`，新电脑上用 `-f 私钥文件` 导入。丢了私钥，已安装的猫就再也收不到更新。
- 公钥写在 `build.sh` 生成的 Info.plist（`SUPublicEDKey`）里，只认这把私钥签过的更新。
- 版本号必须一次比一次大；`CFBundleVersion` 用构建时间，Sparkle 靠它比较新旧。
- 1.0 版本没有更新功能，拿到 1.0 的人要手动装一次 1.1 之后才能自动更新。

只装了 Command Line Tools、没有 Xcode 时，SwiftPM 无法构建，所以这里直接用 `swiftc`。

测试用启动参数（直接运行 `build/猪猪包.app/Contents/MacOS/ZhuzhuPet`）：
- `--drink-now`：启动后马上去喝水
- `--lift-test`：模拟拎起、甩动、扔出去
- `--water-test`：马上来要水，9 秒后模拟点「加水」
- `--stretch-test`：马上伸个懒腰
- `--wall-test`：马上去屏幕边扒墙磨爪
- 环境变量 `ZHUZHU_LOG=1`：每 0.1 秒打印状态、窗口位置、摆动角度

## 行为

- **大部分时间蹲坐**：每次坐 1～4 分钟。坐着时偶尔眨眼、慢眨眼、瞳孔放大、舔鼻子、眯眼笑，白天偶尔竖瞳；也会舔爪子洗脸、打哈欠（晚上更常打）。
- **走动**：坐够了会站起来走到别处再坐下，站起和坐下都有过渡动作。
- **睡觉**：23:00～7:00，或者你离开电脑超过 10 分钟，它会打个哈欠、趴下抬着头犯困（慢眨眼），过一阵下巴贴地、身体摊开睡着（缓慢呼吸）。姿势参照实拍照片。白天偶尔小睡，你回来后会自己醒。点它一下会叫醒它。
- **夜间眼睛**：19:00～7:00 眼睛是深色的大瞳孔。
- **拎起来**：鼠标移到猫身上是张开的手，按住拖动就捏着后颈拎起来。身体会随手的动作晃动，刚拎起时吃惊，过一会儿放松，拎太久会蹬腿挣扎。慢慢松手它会掉下来；甩着松手会被扔出去，撞到屏幕边缘会反弹，落地时会压扁再弹回，然后坐下或舔毛。
- **喝水提醒**（默认每 45 分钟）：时间到了空水碗出现，猫走过去看看空碗，抬头跟你说渴了：要你先喝一杯，再帮它把碗加满。点「我喝了，加水！」记一杯，水碗从空到满倒上水，猫喝起来，喝完报今天第几杯（第 1 杯、第 8 杯有特别的话）、冒小心，水碗收起（设置成「一直显示」时除外）。点「等会儿」它会委屈地等着，10 分钟后再来，越问越可怜；一直不理它，5 分钟后它自己走开。你主动点「我喝水了」或点水碗，它也会跑去陪你喝一口。你不在电脑前或睡觉时间不提醒。
- **久坐提醒**（默认连续用电脑 50 分钟）：猫站起来伸个大懒腰并提醒你起来活动。中间离开电脑 5 分钟以上会重新计时。
- **躲在屏幕边上探头**：把猫拎到屏幕左边或右边边缘松手，它会躲到边后面，只探出半个头偷看（参照实拍）。鼠标靠近它就缩回去只露个耳朵尖，鼠标停在旁边一会儿它又好奇地探出来；偶尔自己缩回去再探头、眨眼。它会一直躲在那里，相当于把它“最小化”：不会自己出来，也不走动。喝水、久坐、日程提醒照常，只是从边上冒气泡，不出来。想让它回来就按住它往屏幕里拖（缩回去只露耳朵时也能抓）。
- **跳上窗口**：偶尔会走到某个窗口下面，跳上它的顶边（矮的一个弧线跳上去；高的会先蹲下瞄准，后腿一蹬、身体拉直，前爪扒住边，后腿蹬几下再爬上去），在上面走走、坐着、舔毛，或者趴下（有时把尾巴垂下来晃，有时尾巴搭在边上偶尔甩一下）。窗口被拖走、关掉或最小化它会掉下来；别的窗口挡住它的位置它会自己跳下来。拎着它松手时，下面有窗口顶边也能落在上面。要喝水、吃虾、睡觉等会先跳下来。只在「保持在最前」时会上窗口。

## 提醒

所有提醒都是猫自己做动作，再冒一个像素风气泡，气泡带按钮，不弹系统通知。气泡总在猫头上方，不挡猫。字体是 Fusion Pixel Font（OFL 许可，见 `Resources/fonts/`）。

- **喝水**：到点后猫守着空水碗说渴了，问你「我喝了，加水！ / 等会儿」。你喝了它才有水喝；「等会儿」= 10 分钟后再来。
- **久坐（屏幕用太久）**：连续用电脑达到设定时间提醒。猫随机二选一：站起来伸个大懒腰问你「起来了 / 等会儿」，或者走到屏幕中间趴下问你「歇一下 / 等会儿」。「等会儿」= 10 分钟后再提醒。离开电脑 5 分钟以上自动重新计时。
- **日程**：菜单里开启后会请求日历权限（只在本机读取）。会议前 5/10/15 分钟，猫走到屏幕中间提醒；开始时再提醒一次。日程里有 Zoom、Google Meet、Teams、腾讯会议、飞书等链接时，气泡里有「加入会议」。
- 你不在电脑前或睡觉时间，喝水提醒会顺延。

## 直接和猫互动

- **右键点猫**：猫头上方弹出快捷按钮：喂虾、逗猫、我喝水了、伸懒腰、设置。
- **摸它**：鼠标在猫身上来回划（不用按键）。坐着时随机反应：多数是打呼噜（蹭、眯眼、冒心），有时伸个懒腰，有时舔舔被摸的地方，有时眯眼“喵～”。趴着或睡着时被摸会“呼噜…”冒心，不起来。
- **摸太多会烦**：5 分钟内摸到第 3 次，它会说“别摸啦”，甩下尾巴（睡着的会先醒），走到屏幕另一边，打个哈欠趴下睡，这一觉至少睡 3～7 分钟。选了“原地坐着”时就原地趴下。
- **晃晕**：在它面前左右来回晃鼠标，它会跟着转头；6 秒内来回 7 次就晕了：头上转圈的小星星、身体摇晃、眯眼，几秒后回过神，之后一小会儿不再跟着鼠标看。
- **点它**：眯眼笑，偶尔“喵～”；睡着时会被叫醒。
- **喂虾**：点“喂虾”后虾跟着鼠标，点一下放到想放的位置，虾掉到地上，猫跑过去叼起来吃掉。
- **逗猫**：红点跟着鼠标在屏幕任意位置。红点在地面附近：远了追，近了压低身子扭屁股再扑。红点在半空、够得着：跑到正下方跳起来用前爪够（跳的高度按红点高度算）。太高：坐着看，偶尔蹦一下说“够不着～”。45 秒不动就结束。
- **看你**：坐着时鼠标在它附近（约 320 点内）移动，它会慢慢把头转向鼠标，8 个方向（左右各 3 档、上 2 档、左上/右上/左下/右下/下各 1 档），鼠标停下或离开就转回来。
- **逗猫的“没意思”**：扑过或跳过一次后，红点还在原处（80 点内）它就走开，红点换到新位置才会再来。玩的时候在任何地方右键就收起红点。
- **发呆时的花样**：东张西望、甩尾巴、舔爪、打哈欠、挠痒痒、打喷嚏、拍空中的小虫、抖耳朵、甩头；坐够了会走动、趴下歇一会儿（不睡）、小睡，偶尔突然疯跑到屏幕另一头，偶尔走到最近的屏幕边，后腿站起来把前爪搭在屏幕边上伸个长懒腰，再左右爪轮流磨爪子（约 6 秒）。
- 坐着时偶尔甩一下尾巴；趴着抬头时尾巴偶尔沿地面甩出去再卷回来，有时连甩两下。
- **小动效**：吃完虾头边冒出几颗粉色小心，被摸得舒服时也会偶尔冒一颗；犯困、睡着时头上飘出 Z。每颗的位置、大小、飘的方向都随机，像素画写在 `Effects.swift` 里。

## 菜单栏

菜单里只放状态和设置。喂虾、逗猫、我喝水了在右键猫弹出的快捷按钮里。伸懒腰、喝水这类动作由提醒或互动自己触发，不在菜单里。

- 今天喝了几杯水
- 提醒：喝水提醒间隔、久坐提醒间隔、日程提醒（开关、提前几分钟）
- 猫：原地坐着 / 继续走动、显示位置（保持在最前 / 只在桌面）、眼睛颜色、大小（小包 / 大包）、水碗（只在喝水时出现 / 一直显示）
- 开机自动启动（第一次运行时自动打开，可在菜单里关掉）
- 检查更新…、当前版本号
- 退出

设置都会记住。
